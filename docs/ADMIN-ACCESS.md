# BTT — Admin Access & Security Model

> **Публичное название бренда:** BTT - мебель для дома и сада  
> **Версия:** 2.0  
> **Дата:** 2026-09-26  

---

## 1. Концепция безопасности

Панель администратора (`/admin`), внутреннее CRM-приложение (`/admin/app.js`) и служебные API-эндпоинты (`/api/*`) защищены на уровне **Cloudflare Workers**:

1. **Серверная аутентификация**:
   - Любое обращение неавторизованного пользователя к `/admin`, `/admin/` или подстраницам перенаправляется сервером:
     ```
     302 Found -> /login.html?redirect=/admin
     ```
   - Запросы к `/admin/app.js` без активной админской сессии немедленно прерываются с кодом `401 Unauthorized`.
   - Сессии хранятся в защищенном хранилище `Cloudflare KV` (`SESSIONS`) с автоматическим временем жизни (TTL) и `HttpOnly`, `SameSite=Lax` cookies.

2. **Защита от индексации поисковыми роботами**:
   - `robots.txt` явно запрещает обход:
     ```txt
     Disallow: /admin
     Disallow: /admin/
     Disallow: /api/
     Disallow: /login.html
     Disallow: /account.html
     ```
   - Middleware безопасности `worker/security-headers.ts` устанавливает HTTP-заголовок:
     ```http
     X-Robots-Tag: noindex, nofollow
     ```
     на любые ответы по путям `/admin*`, `/api*`, `/login.html`, `/account.html`.

3. **Отсутствие утечек в публичной витрине**:
   - Из клиентских скриптов витрины (`assets/account.js`, `assets/site.js`) полностью удалены динамические инъекции кнопок входа в админку (`.acc-admin-btn`, `.foot-crm-link`).
   - Обычные посетители и клиенты видят только публичный интерфейс личного кабинета покупателя (история заказов, статус доставки, избранное).

## 2. Процедура входа администратора

1. Администратор переходит по адресу:
   ```
   https://bententrade.uz/login.html?redirect=/admin
   ```
2. Вводит учетные данные (логин/пароль администратора, настроенные в D1/KV).
3. При успешной проверке создается защищенная сессия с ролью `admin` в Cloudflare KV, выставляется cookie сессии, и происходит редирект в `/admin`.
4. Для выхода из панели управления вызывается `POST /api/auth/logout`, очищающий сессию в KV и аннулирующий cookie.
